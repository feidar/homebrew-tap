# Feidar Homebrew Tap

Official Homebrew tap for apps by [Matouš Janeček](https://janecek.app).

## Available Casks

| App | Description | Install Command |
| --- | ----------- | --------------- |
| **MDConverter** | Offline document & media to Markdown converter powered by MarkItDown | `brew install --cask feidar/tap/mdconverter` |
| **PortWatch** | Menu bar viewer for open TCP/UDP ports with one-click process termination | `brew install --cask feidar/tap/portwatch` |

## Installation

You can install either app directly with:

```bash
brew install --cask feidar/tap/mdconverter
brew install --cask feidar/tap/portwatch
```

Or tap the repository first:

```bash
brew tap feidar/tap
brew install --cask mdconverter
brew install --cask portwatch
```

## Updating

Apps installed from this tap include built-in Sparkle auto-updates, or you can update via Homebrew:

```bash
brew update
brew upgrade --cask
```
