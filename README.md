# Feidar Tap

## How do I install these formulae?

`brew install feidar/tap/<formula>`

Or `brew tap feidar/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "feidar/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
